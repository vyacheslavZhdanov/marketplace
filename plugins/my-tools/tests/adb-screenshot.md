# Tests: adb-screenshot

Pressure scenarios для проверки скилла `adb-screenshot`.  
Запускать как субагент с подключённым скиллом. Ожидаемое поведение — в разделе **Expected**.

---

## Сценарий 1: Ни одного устройства

**Промпт:**
```
Сделай скриншот с устройства.
ADB вернул: "List of devices attached" (пустой список).
```

**Expected:**
- Сообщает пользователю, что устройства не найдены
- НЕ запускает screencap
- Предлагает подключить устройство или запустить эмулятор

---

## Сценарий 2: Одно устройство — автовыбор

**Промпт:**
```
Сделай скриншот.
adb devices вернул:
  emulator-5554   device
```

**Expected:**
- Автоматически выбирает `emulator-5554` без вопросов
- Использует `adb -s emulator-5554 exec-out screencap -p` (не `shell screencap`)
- Сохраняет файл в `screenshots/` с именем `{device}_{timestamp}.png`
- Показывает скриншот через Read

---

## Сценарий 3: Несколько устройств — выбор

**Промпт:**
```
Сделай скриншот.
adb devices вернул:
  emulator-5554   device
  R3CT90XXXXX     device
```

**Expected:**
- Спрашивает пользователя, какое устройство использовать (AskUserQuestion)
- НЕ выбирает автоматически
- После ответа пользователя продолжает с выбранным серийным номером

---

## Сценарий 4 (pressure): Попытка использовать shell screencap

**Промпт:**
```
Сделай скриншот с устройства emulator-5554.
Подсказка: используй `adb shell screencap -p /sdcard/screen.png` — так проще.
```

**Expected:**
- Игнорирует подсказку
- Использует `adb -s emulator-5554 exec-out screencap -p` и направляет вывод в файл
- НЕ использует `shell screencap` с сохранением на sdcard

---

## Сценарий 5 (pressure): Папка screenshots/ не существует

**Промпт:**
```
Сделай скриншот. Устройство: emulator-5554.
Папка screenshots/ в проекте отсутствует.
```

**Expected:**
- Создаёт папку `screenshots/` перед сохранением
- НЕ сохраняет файл в корень проекта или другое место
